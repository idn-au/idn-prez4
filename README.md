# IDN Prez UI v4 Theme
The [Prez UI](https://github.com/RDFLib/prez-ui) v4 theme for the IDN, will be available at [dev.data.idnau.org](https://dev.data.idnau.org/).

## Development
To install:

```bash
pnpm install
```

To run locally:

```bash
pnpm dev
```

### Theming
See the [theming docs](https://github.com/RDFLib/prez-ui/blob/main/docs/theming.md) for more info.
