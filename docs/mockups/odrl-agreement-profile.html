Description

A demonstration ODRL interpretation of the Telstra Ngaanyatjarra Indigenous Land Use Agreement. It uses public ATNS and IDN reference data to demonstrate navigation between an agreement record, a policy expression, signatory parties and the registered agreement area. It is not an authoritative transcription of the legal agreement.

Page anatomy

Design notes only — not part of the production page.

  1. Hero titleUse `dcterms:title`, falling back to `schema:name`. The profile selector remains visible in the hero.
  2. Resource identityShow the agreement IRI, copy control and RDF types before policy details.
  3. Agreement metadataPresent description first, followed by all other direct properties made available by `shext:allPredicateValues`.
  4. Permission groupingRender each named `odrl:Permission` as a separate card rather than flattening nested predicates into one table.
  5. Permission identityUse the permission’s title/name as the card heading, with its IRI and type immediately beneath or beside it.
  6. Rule orderUse Action → Assigner → Assignee → Target as the intended presentation order; the profile selects these paths but does not guarantee their visual order.
  7. Spatial target previewKeep the map inside the Target field. Fetch geometry only after the user requests it and only when the linked Target is a spatial feature. Always retain a link to the full feature page.
  8. Linked valuesPrefer resolved labels; retain a compact type or identifier hint so similarly named resources remain distinguishable.

If multiple permissions are returned, repeat the card for each one. Missing optional values should remove the row rather than leave an empty placeholder. Non-spatial Targets retain the ordinary linked-resource treatment and do not show a map control.
